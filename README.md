# TwinBox

**Your machine's twin — with none of your keys.**

让编程 agent（Claude Code、Codex、opencode2）在桌面沙箱里获得完整的工作环境，
但沙箱内不含任何凭据：API key、token、密码全部留在宿主侧。

> 状态：v0 初始化，设计与实现进行中，暂不可用。
> 目标：2026-10-26 提交（1024 黑客松）。

## 设计要点

- **隔离**：bubblewrap + 独立网络命名空间，出站默认拒绝。
- **凭据**：沙箱内只出现占位符，真实值由宿主侧代理在边界注入。
- **MCP**：服务端运行在宿主，沙箱内配置不含任何敏感信息。
- **易用**：不写配置文件，不重新录入机器上已有的 key。

设计与代码随后按 PR 提交。
