# 威胁模型

状态：基线 v0（2026-10-24）。威胁假设与不做清单是判据，改动需走 PR。

## 1. 信任边界

```
可信      │  宿主：twinbox CLI、密钥库、broker、MCP gateway、用户
──────────┼─────────────────────────────────────────────────────
不可信    │  沙箱内一切：agent、模型输出、项目代码、MCP 响应、安装的依赖包
──────────┼─────────────────────────────────────────────────────
半可信    │  经 broker 访问的外部服务
```

宿主「可信」只体现在它持有密钥这一点上。**任何处理 agent 可控输入的进程**
（包括 broker 和每个 MCP server）都按潜在 confused deputy 对待：
必须与它不需要的秘密隔离。

## 2. 假设

- **A1** agent 已被完全攻陷。假设任意时刻都可执行任意代码，而不是「提示变坏之后」。
- **A2** 提示注入必然发生：agent 读到的文件、issue、网页、工具返回都可能带指令。
- **A3** 用户不会读文档、不会手改配置、遇到弹窗会直接点「允许」。
- **A4** 内核未被攻陷（不防御 0day 提权）。
- **A5** 模型供应商只返回模型输出，不主动作恶。

## 3. 资产

| ID | 资产 | 丢失后果 |
| --- | --- | --- |
| A1 | LLM 供应商密钥 | 资金损失、账号被接管 |
| A2 | Git / CI token | 供应链投毒 |
| A3 | 云凭据 | 基础设施被接管 |
| A4 | 宿主 SSH 私钥、`ssh-agent` socket、keychain、浏览器 cookie | 身份被接管、横向移动 |
| A5 | agent 自身历史文件（`~/.claude`、`~/.codex`、`~/.dsh`） | 历史密钥与客户数据 |
| A6 | 项目 `.git` 历史 | 历史提交里残留的密钥 |
| A7 | 生产系统 | 故障与数据损失 |

## 4. 威胁与缓解

| ID | 威胁 | 缓解 | 残留风险 |
| --- | --- | --- | --- |
| T1 | agent 从环境变量/参数读到凭据 | 只注入占位符，真值不出宿主 | 低 |
| T2 | agent 扫描文件系统找密钥 | 宿主 home 永不挂载；生成空 `$HOME`；`.git` 按策略处理 | 低 |
| T3 | agent 读 `/proc/*/environ`、core dump、自身日志 | 沙箱内本来就不存在真值 | 低 |
| T4 | agent 向任意地址外发数据 | `--unshare-net`，仅 loopback，白名单 broker | 低（防的是数据，不是密钥） |
| T5 | agent 把 broker 当「万能代理」使用 | 按目标 + 方法级白名单、限速、审计 | **中** |
| T6 | agent 滥用合法 MCP 工具（删仓库、改权限） | 参数级策略 + 破坏性动词审批 | **中** |
| T7 | agent 把窃取的数据写进项目目录 | 提交前可公开性扫描 + diff 复核 | 中 |
| T8 | MCP server 本身恶意 | 每个 server 独立身份、无宿主 home、默认无网络 | 中 |
| T9 | 密钥泄漏进 TwinBox 自己的 git 历史 | `.gitignore` 黑名单 + pre-commit 扫描 | 低 |
| T10 | 沙箱内获得 `ssh-agent` socket，无需读私钥即可签名 | socket 永不挂载；需要时改走宿主侧受策略约束的签名代理 | **中高** |
| T11 | 通过 `ssh -L/-R/-D` 建立通用隧道，绕过出站白名单 | SSH 出站默认禁止；放行时只允许到指定主机端口，禁隧道与转发 | **中高** |
| T12 | `~/.ssh/config`、`known_hosts` 泄漏内网拓扑 | 永不挂载，按需生成最小条目 | 中 |

**T5、T6、T10、T11 是本方案诚实的弱点**：它们靠策略与审计缓解，不靠隔离。
任何对外表述都不应越过这一层。

## 5. 明确不在范围内

- 内核/虚拟化逃逸、推测执行侧信道
- 物理接触、恶意固件
- 模型供应商或宿主操作系统账号被攻陷
- 资源耗尽型 DoS（仅部分：有限额）
- **任务本身要求 agent 读取的数据的机密性**

## 6. 需要被测试的不变式

1. **可公开性**：沙箱完整快照中不含任何秘密。
2. **零挂载**：黑名单中的路径在沙箱内不存在。
3. **出站对账**：每个出站请求恰好对应一条审计记录。
4. **可撤销**：宿主删除凭据后，下一次调用立即失败。
